1. 本说明的适用范围

本说明介绍你使用饮有数、访问本网站或联系支持时，相关信息如何被处理。饮有数是一款个人饮品日记，帮助你记录饮品并理解已有的营养信息，无需另外注册饮有数账号。开发者公开显示名为 Wchao.Jim.。如有隐私问题，请联系 wchao.jim@gmail.com。

2. 饮品记录与偏好设置

App 在本机保存你输入或选择记入的信息，例如饮品名称、饮用量、日期、营养数值、备注和来源文字。这些信息用于展示日记、计算汇总，以及让你查看记录的依据。已保存的记录可能保留早期版本和当时的来源快照。

常用饮品、其默认杯量和 App 偏好保存在本机。目前，常用饮品及其默认杯量不参与 iCloud 同步，也不包含在 JSON 备份中。App 不含广告或第三方分析 SDK，我们不出售你的饮品记录数据。

3. 相机、照片与标签识别

你可以通过 Apple 系统照片选择器选取一张图片，或允许相机访问以拍摄营养标签。识别在你的设备上进行，饮有数不会把标签图片发送给云端 OCR 或 AI 服务。识别得到的文字和计算结果可能成为已保存记录的一部分。

当前自动识别流程在内存中处理选取的图片，不会将原图存为记录证据。对于你此前选择保留的标签图片，现有图片仅保存在本机，不参与当前的 iCloud 同步，也不包含在 JSON 备份中。系统照片库和设备备份是另外的数据保存途径。

4. 可选 iCloud 与外部副本

当你选择使用当前提供的 iCloud 功能时，饮品记录、来源文字、记录的早期版本、删除信息及同步所需的信息可能被发送到你本人的 iCloud 私有数据库。该服务由 Apple 通过你的 Apple 账户提供。饮有数没有为你的日记另设自建服务器。

预览合并时，App 会联系 Apple 核对当前账户并读取云端版本。你核对并确认合并后，才会授权本次会话；随后选择立即同步才会上传。离开数据页面、进入后台或选择停止同步，会结束本次会话授权。已经发出的请求仍可能已到达 iCloud。返回后需要重新预览与确认，目前不提供持续后台同步。

本地保存与云端确认不同：一条已保存的记录仍可能等待上传。停止同步不会清除已经保存在 iCloud 的信息。导出文件、系统照片库、设备备份，以及你放入云盘的文件也可能产生外部副本。Apple 对其服务的信息处理方式见 Apple 隐私政策。

5. 购买与 Pro 权益

App Store 购买由 Apple 处理。饮有数使用 Apple 提供的购买和权益信息判断 Pro 访问权限，并在本机记录成功标签识别的免费使用额度。这些信息与饮品记录分开保存，不包含在日记的 JSON 备份或日记同步中。

Pro 是一次购买的非消耗型商品，没有订阅或自动续费。购买页面显示 App Store 为你所在商店地区提供的价格。饮有数不会从 Apple 获得你的完整支付卡信息。

6. 你发送给支持的信息

如果你发送支持邮件，我们会收到你的邮箱地址、邮件内容，以及你主动添加的附件。这些信息用于理解和答复你的请求。App 的反馈链接只会打开你的邮件 App，不会自动附加日记、照片或诊断文件。

请只提供解决问题所需的信息，并尽可能遮挡截图中的私人内容。支持邮箱通过 Gmail 接收邮件，其服务受 Google 隐私政策约束。

7. 访问本网站

本网站托管在 GitHub Pages。我们没有在这些网页中添加广告、分析脚本、跟踪像素或 Cookie。托管服务商仍会处理提供和保护网站所需的信息。GitHub 说明，即使访问者没有登录，也会出于安全目的记录并保存其 IP 地址。详情见 GitHub Pages 与数据收集说明。

8. 保存期限与删除的实际含义

删除一条饮品记录会让它不再出现在常规日记列表中，但不会永久清除其全部已存储内容。记录的早期版本和删除信息仍保留在本机；如果已经同步，也会保留在你的 iCloud 私有数据中。App 目前不提供彻底清除每个已保留修订版本的功能。请勿把删除可见记录或停止同步理解为这些副本已被清除。

导出文件、照片库中的原图和备份各有独立的保存与删除控制。支持邮件会在处理你的请求及相关后续事项所需的期间内保留。如因法律要求或实际争议需要延长保留，范围和时间应限于该目的所必需。

9. 你的选择与隐私请求

你可以查看和编辑记录，在设备设置中管理相机权限，选择是否使用 iCloud，以及导出当前 JSON 格式支持的日记数据。使用 App 的删除操作时，上述删除限制同样适用。

根据适用法律，你可能有权访问、更正、删除、获取个人信息副本，或限制个人信息的使用。你可以通过上方邮箱提出请求，也可以联系相关数据保护机构。具体可采取的措施取决于所涉及的信息和适用要求。

10. 信息安全

饮有数使用 Apple 平台提供的存储和服务机制。App 不会索取你的 Apple 账户密码或支付卡号，也不申请位置、通讯录、麦克风或 HealthKit 访问权限。请保护好设备，并留意备份和分享设置允许哪些操作。

任何存储或传输方式都无法消除全部风险。本说明不承诺特定加密等级、同步永不中断，或每份数据均可恢复。请勿向支持邮箱发送密码或支付信息。

11. 儿童

饮有数面向成年人的个人使用，并非为儿童设计。如果你认为有儿童向支持邮箱发送了个人信息，请联系我们，以便了解具体情况并采取适当措施。

12. 本说明的更新

本说明更新后会在此页面公布，并更新日期。App 功能或你的使用选择发生变化时，请重新查看。隐私问题和请求可发送至 wchao.jim@gmail.com。
