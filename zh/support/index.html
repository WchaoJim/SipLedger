如何描述问题

先简要说明发生了什么、你希望出现什么结果，以及 App 和 iOS 版本。截图为可选项，发送前请遮挡个人信息。

不要发送 Apple 账户密码、验证码、银行卡信息，也不必为了报告一个问题就附上完整的饮品备份。App 的反馈邮件入口不会自动附带记录或设备信息。

常见问题

我的记录保存在什么地方？

记录优先保存在本机。可选的 iCloud 同步使用你当前 iCloud 账户的私人数据库。本地保存与 iCloud 确认是两个不同的状态。

请分别查看可见记录、待同步版本、云端已确认或已下载版本，以及冲突数量。待同步为 0，并不单独证明另一台设备已经收到数据。

怎样备份或恢复记录？

打开设置 → iCloud 同步与备份，在 JSON 备份区域选择导出，并将文件保存到以后能找到的位置。

恢复时，选择 JSON 文件并预览导入。先核对新增、跳过、删除标记和账户归属，再确认导入；也可以在预览阶段取消。

完整 JSON 备份包含饮品记录、常用饮品、独立杯量预设、完整来源文字及各集合的删除标记。它不包含标签图片、购买权益、账户绑定、同步授权或云端确认。旧版仅含记录的 JSON 仍可导入；预览会明确显示常用和杯量未包含，现有常用和杯量不会因此被删除。导入存在冲突时不会写入，先核对冲突内容。

iCloud 为什么没有同步？

在“数据与同步”页预览当前 iCloud 合并，核对后确认开启本次会话，再点立即同步。离开此页或将 App 切到后台，会停止本次会话的同步授权。

若操作失败，先保留数据，再检查网络、iCloud 登录和可用空间，并根据错误提示手动重试。账户或数据变化后需重新预览。持续失败时请联系支持。

停止同步不会删除已有云端数据。不要通过卸载 App 或清空数据来排查同步问题。

常用饮品和杯量怎样同步？

常用及其默认杯量、独立杯量预设和饮品记录共用同一次 iCloud 合并预览与确认。两台设备需使用相同 iCloud 账户和支持这三类数据的版本，并分别完成同步。请按集合查看待传、已确认和冲突情况；本机待传为零并不证明另一台设备已收到数据。编辑常用或选择杯量预设不会自行改写过去的饮品记录。

怎样恢复饮有数 Pro？

从设置打开饮有数 Pro，选择恢复购买，使用原来购买 Pro 的 Apple 账户，等待 App Store 核验结果。

Pro 只有一项永久买断，没有订阅或自动续费。恢复后仍显示免费状态时，可以把页面提示发给支持，不要发送账户密码。

购买价格与币种由 App Store 商店地区决定，切换 App 中英文不会切换币种。退款请求请参阅 Apple 退款说明。

标签识别错误，可以修改或撤销吗？

请对照包装原文核对数值和单位。填写有效实饮量、且标签至少有一项可计算结果时，识别可自动记入。同次采集中的变化会更新同一杯，也可以使用该会话的撤销操作。

未识别到糖量表示未知，不等于零。请对照原标签核查结果。已保存记录的实饮量可以修改，但自动识别的营养原值目前不能直接编辑。错误结果可以在采集会话中撤销，或删除错误记录后重新手动记入。

删除记录意味着什么

删除饮品记录、常用饮品或杯量预设，会将其从正常列表中移除，但不会永久清除其全部已存内容。早期版本和删除信息仍保留在本机；如果已同步，也可能保留在你的私人 iCloud 数据中。App 目前不提供彻底清除全部历史修订的功能。停止同步也不会清除已有副本。

当前 App 尚无彻底清除全部已存版本的功能。已导出的文件、保留的图片、系统备份也是独立副本，停止同步或删除列表中的一条记录不会一并清除它们。

隐私或删除请求可以通过邮件联系。我们可以解释现有控制方式，并处理你通过邮件提供的信息；我们没有可供远程查看或清除你私人饮品库的自建服务器。

妥善保护你的记录

  • 使用 Apple 提供的安全设置保护 iPhone 和 Apple 账户。
  • 将 JSON 备份当作私人文件保管。它包含完整来源文字，饮有数不会为其设置文件密码。
  • 分享备份或图片前，核对接收方与保存位置。
  • 开启 iCloud 会话前，核对账户归属与合并变化。

发现疑似安全问题，请通过邮件私下报告安全问题。先提供受影响功能，以及使用虚构数据可复现的步骤。不要在公开 GitHub issue 中发布私人记录或账户凭据。

完整的信息处理说明见隐私政策。
